# Contributing

Thanks for helping out! Please read the [README](README.md) first.

## Before you start

1. Open an issue.
2. Fork and branch.
3. Run the tests:

    ```sh
    cargo test
    ```

## Style

- Keep functions small.
- Document public items.
- See the [style guide](docs/guide.md#style).

## Checklist

- [ ] Tests pass
- [ ] Docs updated
- [ ] Linked the [tracking issue](https://example.com/issues)

# Guide

Back to the [README](../README.md).

## Style

Widgets should be small. Here is an example:

```python
w = Widget("x")
assert w.ok
```

## Rendering

Rendering turns a widget into HTML like <span class="w">x</span>.

See also the [installation section](../README.md#installation).
